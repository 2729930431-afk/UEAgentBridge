# UE 0.2.0

Codex plugin for Unreal Editor, powered by EngineWire 0.6.0. Requires Node.js 20.19+ and a UE project with the matching EngineWire native plugin installed. UE 5.6.1 was validated locally; other versions are not independently verified here.

Configure the target project before using editor tools:

- From the repository, run `scripts/Configure-UE.ps1 -ProjectPath <path-to-uproject>`.
- The launcher reads `~/.config/UEAgentBridge/config.json`: `projectPath` is a project folder or .uproject, `endpoint` defaults to `http://127.0.0.1:3000/mcp`.
- Environment variables `UE_PROJECT_PATH` and `UNREAL_MCP_URL` override that file. `UE_AGENT_BRIDGE_CONFIG` selects a different config file, allowing separate launch configurations for different editor sessions.
- Reload Codex after changing configuration. Use `unreal` search → describe → execute; do not guess parameters.
- The launcher never starts Unreal Editor. Editor actions require the user's intended editor session and a matching project token generated by EngineWire under `Saved/MCP/capability-token`.

默认只保证相关编译通过；只有用户明确要求，才专门启动或重启 UE，或进行 PIE、游戏运行、自动输入与重连测试。纯文档和 Skill 修改只检查格式。过去任务的测试许可不自动延续。

The server runtime is vendored from upstream without changes; see `server/LICENSE`. Full source, installation instructions and attribution are in https://github.com/2729930431-afk/UEAgentBridge.
